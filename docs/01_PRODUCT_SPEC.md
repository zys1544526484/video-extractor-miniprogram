# 产品规格

## 页面

- 首页：视频提取标题、分享文案输入、粘贴、开始提取、免费状态、教程、FAQ、我的；首页不预选画质。
- 结果页：视频、图片、标题三个 Tab。视频 Tab 展示真实可用源列表、实际清晰度/大小、预览、复制安全下载链接和保存视频；图片 Tab 展示可保存的解析图片；标题 Tab 展示作品标题和分享文案并支持复制。
- 提取记录：任务完成后保留 24 小时，未下载的结果可从记录中重新打开并重新签发短期媒体地址。
- 教程：6 步内说明复制、粘贴、解析、预览和保存。
- FAQ：免费模式、失败、水印、保存和临时缓存。
- 我的：默认应用身份、免费保存状态、隐私、教程和 FAQ。

## 不做

会员、充值、卡密、积分、收藏、批量下载、用户上传、长期媒体托管、烧录水印擦除、访问控制绕过。

首页不要求用户预选画质；解析器返回一个或多个真实公开源，由结果页展示实际清晰度和大小，用户在源选择底部面板中切换。不得用修改显示文字的方式伪造源，也不得把降档结果冒充原视频。
