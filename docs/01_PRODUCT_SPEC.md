# 产品规格

## 页面

- 首页：视频提取标题、分享文案输入、原视频/720P/540P 画质选择、粘贴、开始提取、免费状态、教程、FAQ、我的。
- 结果页：平台、标题、封面/视频预览、媒体信息、保存视频、重新提取、下载进度和错误状态。
- 教程：6 步内说明复制、粘贴、解析、预览和保存。
- FAQ：免费模式、失败、水印、保存和临时缓存。
- 我的：默认应用身份、免费保存状态、隐私、教程和 FAQ。

## 不做

会员、充值、卡密、积分、历史、收藏、批量下载、用户上传、长期媒体托管、烧录水印擦除、访问控制绕过。

画质选择表示目标档位：原视频取最高公开且可保存的兼容源；720P/540P 取不高于目标值的最高公开档位。平台没有完全相同的分辨率时必须展示实际结果，例如“480P H.264（540P 档）”。超过微信保存边界时提示用户主动选择更低档，不得静默降级。
