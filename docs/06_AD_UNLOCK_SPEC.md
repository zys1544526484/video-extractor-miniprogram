# 广告与下载权益

当前发布模式为 `free`：登录用户可直接下载，前端不创建广告对象、不展示 Banner 或广告占位，广告接口返回 `FEATURE_DISABLED`。以下规则仅作为未来切换 `rewarded_ad` 模式时的保留设计。

- 展示型广告只承担持续曝光，不阻塞主流程。
- 激励广告只在用户首次保存且下载权益无效时出现。
- 展示广告前先调用 `/entitlement/ad-attempt`；服务端签发短期、绑定用户、一次性的随机凭证并限制签发频率。
- `RewardedVideoAd.onClose` 只有 `isEnded === true` 才携带该凭证调用服务端完成接口；中途关闭、过早、过期、重放或其他用户的凭证都不能创建新权益。
- 服务端计算 `unlock_until = server_now + 24h`，有效期内重复事件不续期。
- 广告结束后自动继续此前挂起的保存动作；中途关闭则不下载。
- Mock 广告必须明显属于开发模式，生产配置出现 Mock 时启动失败。

当前凭证机制不能替代微信侧广告结算证明。没有官方服务端观看回调时，后端只能约束伪造、重放和频率，真实奖励与收益仍需 Gate B 使用真实广告单元和真机验证。
