# UI 规格

- 批准基准：`design/home-approved.png`、`design/result-approved.png`。
- 主色 `#07C160`，背景 `#F7F8FA`，表面 `#FFFFFF`，正文 `#1F1F1F`，次文 `#8A8A8A`。
- 微信原生导航与安全区；低装饰、低阴影、16–24rpx 圆角。
- 首页首要焦点是输入和“开始提取”；结果页首要焦点是视频和“保存视频”。
- 首页输入框下方使用三段式画质选择，顺序固定为原视频、720P、540P，默认原视频；解析期间不可切换。
- 源文件超过服务器 2GiB 暂存上限时提示改选较低画质；可处理的大文件自动压缩。结果页展示实际分辨率、编码和“自动压缩”说明，不把降档结果写成原视频。
- 首版 `free` 模式不渲染 Banner、激励广告或广告占位；后续仅在 `rewarded_ad` 模式且存在真实 adUnitId 时显示。
