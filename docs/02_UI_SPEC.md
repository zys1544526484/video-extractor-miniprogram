# UI 规格

- 批准基准：`design/home-approved.png`、`design/result-approved.png`。
- 主色 `#07C160`，背景 `#F7F8FA`，表面 `#FFFFFF`，正文 `#1F1F1F`，次文 `#8A8A8A`。
- 微信原生导航与安全区；低装饰、低阴影、16–24rpx 圆角。
- 首页首要焦点是输入和“开始提取”；不显示原视频/720P/540P预选控件。
- 结果页固定保留“视频 / 图片 / 标题”三个 Tab。视频 Tab 的视频信息区将实际清晰度、实际大小和“源1/源2”小按钮放在同一行；源按钮仅在后端返回至少两个真实源时出现，点击后从底部弹出面板，显示编号、实际清晰度、实际大小和当前选择。切换后预览、信息、复制链接和保存目标都使用新源，不保留独立的大型视频源卡片。
- 图片 Tab 仅显示后端安全落盘并签发短期地址的图片，没有图片时显示空状态；标题 Tab 显示标题与分享文案，提供复制标题和复制全部。
- 源文件超过服务器暂存上限时按后端规则处理或返回明确错误；结果页始终展示实际分辨率、编码和大小，不把降档结果写成原视频。
- 首版 `free` 模式不渲染 Banner、激励广告或广告占位；后续仅在 `rewarded_ad` 模式且存在真实 adUnitId 时显示。
